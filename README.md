# Streak Lite

A local-first daily habit tracker for Android and iOS. No account, no cloud, no paid services.

## Run it this week

1. Install [Node.js LTS](https://nodejs.org/) if needed.
2. Install **Expo Go** on your phone from the Play Store or App Store.
3. In this folder:

```bash
npm start
```

4. Scan the QR code with Expo Go (Android: Expo Go; iPhone: Camera app).

iOS Simulator is not available on Windows. Use a physical iPhone with Expo Go, or skip iOS until you have a Mac.

## What is included

- Add, edit, and archive habits
- Check off today
- 7-day history and streak count (local calendar date)
- Optional daily reminder (device notifications)

## Share with testers

Send them Expo Go plus the QR from `npm start` while your computer and their phone are on the same network (or use Expo’s tunnel option if that fails).
